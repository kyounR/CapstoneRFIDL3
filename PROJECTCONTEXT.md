Project: RFID-based contactless fare payment system for CALTRANSCO.
Stack: Django + Django REST Framework backend, MySQL database, React frontend.
Stage: MVP only. No hardware integration yet — RFID taps will be simulated via
a REST endpoint that an ESP32 will call later. No styling/UI polish needed,
plain HTML forms and tables are fine for now. Focus on correct data flow and
working endpoints over appearance.
